# UI Workbench contributor guide

This repository contains reusable guidance for interface design decisions and
prototype selection. It does not define the product rules for projects that use
the skills.

Read the target project's contributor rules, accepted decisions and current
implementation before applying either skill. Treat missing requirements as
unknown, not as permission to invent them.

Do not send private briefs, fixtures, screenshots, source code or user data to
an external model without authorization for that data flow. Do not incur model
spend, publish artifacts or change project files unless the user asks.

A prototype score is not a usability result. A selected design is not product
implementation approval. Keep generated runs and captures out of version
control unless the target project approves them.

Update the script digests in
`.github/skills/ui-prototype-council/SKILL.md` when a bundled script changes.
Run the tests that cover the changed behavior.
